# Changelog

All notable changes to the Project Blue Horizon design system are documented here.

## 1.0.0-preview — 2026-10-20

- Consolidated foundations, button hierarchy, forms, feedback, tables, icons, patterns, and accessibility guidance from the supplied references.
- Added WCAG contrast examples and updated action colors to match the revised button standard.
- Added reusable CSS tokens, JSON token export, framework-free component styles, and password/dialog behaviors.
- Added responsive navigation, reduced-motion support, keyboard focus guidance, and release ownership checklist.
- Added shared mobile layout guidance and platform notes linking to Material Design/Android accessibility and Apple Human Interface Guidelines.
- Reorganized the site into separate Overview, Foundations, and Components pages with shared navigation and stylesheet; grouped component references beneath the Components heading.
- Added a global addition-request link and a local form that creates a downloadable or copyable Markdown request.
- Marked owner, support policy, token generation, security review, and icon font packaging as decisions still required before a stable release.
